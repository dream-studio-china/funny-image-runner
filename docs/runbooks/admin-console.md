# Runbook：后台管理控制台

管理后台入口为 `/admin`。它使用部署环境的 `ADMIN_API_TOKEN` 登录，并创建 8 小时有效的 HttpOnly、SameSite=Strict 管理员会话。管理后台不是公开注册页面；不要把管理员 token 交给客服、买家或放入浏览器脚本。

## 登录

1. 确认已设置 `ADMIN_API_TOKEN`，数据库已应用最新 migrations，且 `/api/health` 正常。
2. 访问本地 `http://localhost:3000/admin` 或生产站点的 `/admin`。
3. 输入与服务端环境完全一致的 `ADMIN_API_TOKEN`。会话到期后重新登录；点右上角“退出”会撤销当前管理员会话。

如果登录失败，确认应用服务端变量和数据库可用，不要通过公开聊天粘贴 token 或完整 `.env.local`。

## 签发或撤销邀请码

进入“邀请码”页：

- 管理员可填预先指定的 `userId`，也可留空并提供稳定 `customerRef` 让服务端派生用户标识。
- 手动签发时可留空订单引用，控制台会生成一个新的唯一引用；淘宝自动发货时仍应直接调用 API，并为每份交付提供可重试且唯一的 `orderRef`。
- 签发成功后复制专属链接，通过私密渠道交给用户。链接是可重复使用的登录 bearer 凭证；控制台不保存或显示旧链接明文。用户退出后可重新打开最初收到的邀请链接登录。
- 邀请码列表显示创建/过期时间、来源、首次登录时间及撤销状态。尚未撤销且未过期的链接无论是否登录过都可撤销；撤销后新的登录会被拒绝，并写入审计事件。撤销邀请码不会撤销用户已有登录会话。
- 若自动发货响应丢失，可对同一用户重试同一个 `orderRef`，API 返回原链接。若用户退出，仍可复用原链接登录；若链接已过期/撤销，使用新的订单引用签发新链接。
- 每条邀请旁的“重新签发”会为同一用户创建一条新的登录链接，并显示在签发面板中；原邀请仍保持有效，需要时再单独撤销。遇到用户丢失链接时，也可先到用户管理的“查看”面板复制已有有效链接。

淘宝自动发货 API 请求格式及幂等契约详见 [邀请码签发 runbook](./issue-invitation-links.md)。

## 用户管理

进入“用户管理”页，可以按 user ID 搜索、查看创建时间、邀请码数及任务数，并启用/停用用户：

- 停用会撤销该用户现有会话，后续 API 请求被拒绝；历史任务和记录保留。
- 重新启用不会恢复已撤销会话；用户需通过新的邀请码重新登录。
- 用户 ID 当前不可改名、删除；后台只展示任务数量，不查看输入/输出图片或用户自定义文字。
- 点击用户行的“查看”可展开该用户的邀请记录并复制有效 code/登录链接。code 是登录凭证，只通过私密渠道交付；已撤销或过期的链接不显示可用 code。旧版 CLI 记录若数据库只有 hash、无加密密文，后台无法恢复明文。

## 分类目录与预设目录

“分类目录”和“预设目录”位于后台不同视图但共享 `/admin` URL。分类/预设都通过弹窗创建和修改；分类支持上传主展示图、排序和启停，预设支持分类归属、主展示图、公开显示字段及启停。

- 新预设需要上传主展示图并选择分类；封面由浏览器直传七牛私有空间，数据库只存资产引用。旧有 `/art/*.svg` 封面保留为迁移回退。
- 预设可录入 ComfyUI API 格式 workflow JSON、正向/负向 prompt、固定 additional JSON 和输入/文本/输出节点映射。保存生成不可变新版本；已有任务继续引用原版本。启用时 workflow 与映射必须通过校验。
- 页面公开 API 不下发 workflow、prompt、additional 或对象 key。风格编辑只是保存配置，并不代表远端 ComfyUI 模型/插件已验证。

## ComfyUI Worker

ComfyUI 页提供本机 Worker 配置说明；后台不会直接探测或控制本机 ComfyUI。按 [ComfyUI Worker runbook](./comfyui-worker.md) 在 ComfyUI 主机配置 `WORKER_TOKEN`、`WEB_API_BASE_URL` 和 `COMFY_BASE_URL` 后运行 Worker。ComfyUI 应仅监听本机回环地址。当前后台尚未展示 Worker 在线心跳。
