# Runbook：后台管理控制台

管理后台入口为 `/admin`。它使用部署环境的 `ADMIN_API_TOKEN` 登录，并创建 8 小时有效的 HttpOnly、SameSite=Strict 管理员会话。管理后台不是公开注册页面；不要把管理员 token 交给客服、买家或放入浏览器脚本。

## 登录

1. 确认已设置 `ADMIN_API_TOKEN`，数据库已应用最新 migrations，且 `/api/health` 正常。
2. 访问本地 `http://localhost:3000/admin` 或生产站点的 `/admin`。
3. 输入与服务端环境完全一致的 `ADMIN_API_TOKEN`。会话到期后重新登录；点右上角“退出”会撤销当前管理员会话。

如果登录失败，确认应用服务端变量和数据库可用，不要通过公开聊天粘贴 token 或完整 `.env.local`。

## 签发或撤销邀请码

进入“邀请码”页：

- 管理员可填预先指定的 `userId`，也可留空并提供稳定 `customerRef` 让服务端派生用户标识。
- 手动签发时可留空订单引用，控制台会生成一个新的唯一引用；淘宝自动发货时仍应直接调用 API，并为每份交付提供可重试且唯一的 `orderRef`。
- 签发成功后复制专属链接，通过私密渠道交给用户。链接是 bearer 凭证；控制台不保存或显示旧链接明文。
- 邀请码列表显示创建/过期时间、来源及已兑换状态。撤销只对未兑换邀请码开放；撤销后兑换会被拒绝，并写入审计事件。撤销邀请码不会撤销用户已有登录会话。
- 若自动发货响应丢失，可对同一用户重试同一个 `orderRef`，API 返回原链接。若链接已撤销，使用新的订单引用签发新链接。

淘宝自动发货 API 请求格式及幂等契约详见 [邀请码签发 runbook](./issue-invitation-links.md)。

## 用户管理

进入“用户管理”页，可以按 user ID 搜索、查看创建时间、邀请码数及任务数，并启用/停用用户：

- 停用会撤销该用户现有会话，后续 API 请求被拒绝；历史任务和记录保留。
- 重新启用不会恢复已撤销会话；用户需通过新的邀请码重新登录。
- 用户 ID 当前不可改名、删除；后台只展示任务数量，不查看输入/输出图片或用户自定义文字。

## 风格配置

进入“风格配置”编辑现有预设的名称、副标题、简介、附加提示文案、心情选项、主题颜色及启用状态。点击保存会递增预设版本；已排队任务保留创建时的版本快照，新任务使用已保存版本。停用后该预设不再出现在用户可选列表。

目前图片只可引用站点现有 `/art/*.svg` 示例资源；后台不上传风格封面，不可新建/删除预设。工作流 JSON、ComfyUI 节点映射仍须等 API 格式 workflow 准备好后接入，当前界面不会执行模型配置。

## ComfyUI 预留区域

ComfyUI 页当前只展示待接入提示，不会探测、启动、停止或改动本地 ComfyUI。后台不通过公网连接 ComfyUI；未来由同机 worker 主动连接云端 API 并调用回环地址的 ComfyUI。
